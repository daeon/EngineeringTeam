# Engineering Handoff

Save handoffs outside the repository unless the user explicitly asks for a repo artifact. Use the OS temp directory when creating a file.

Redact secrets, tokens, passwords, private keys, personal data, and environment-specific credentials.

Reference existing artifacts by path or URL instead of duplicating them.

House style: each section should be compact and evidence-first. Prefer table
columns ordered as item/claim, evidence, confidence, risk or impact, next action.
