Generated outputs under `agents/`, `.codex/agents/`, `.github/agents/`, and `skills/engineering-team/assets/agents/` are intentionally excluded from edit recommendations except as consumers of `agents-src/*.yaml`.

## Hard Validator Constraints

The following anchors are hard constraints from `skills/engineering-team/scripts/validate-package.py` and `scripts/validate-codex-package.py`. Proposed edits below must preserve these exact headings or strings unless validators are updated in the same change.

- Required manifests: `.codex-plugin/plugin.json`, `.claude-plugin/plugin.json`, `.cursor-plugin/plugin.json`, `gemini-extension.json`, and `package.json` must each contain `name` and `version`.
- Codex, Claude, and Cursor manifests must keep `skills` as `./skills/`; Cursor must keep `agents` as `./agents/`; Claude marketplace source must be `./`.

## Distillation Sequence

1. Preserve all hard validator anchors first; treat `validate-package.py` and `validate-codex-package.py` as the edit contract.
2. Shorten public narrative docs before touching agent copy: `docs/design.md`, `docs/workflow.md`, and `docs/specialists.md` duplicate the README and reference layer most heavily.
3. Merge marketing/demo overlap by keeping one canonical launch/value narrative and letting `docs/demo-script.md` remain a presenter script.
4. Merge or cross-reference internal reference overlap only when artifact anchors remain stable: likely targets are `output-contracts.md`, `subagent-context-policy.md`, `diagnosis-loop.md`, and `visual-review-reports.md`.
5. Do not edit generated agent outputs directly; if role copy needs distillation, edit the corresponding `agents-src/*.yaml` and regenerate with the package scripts.
