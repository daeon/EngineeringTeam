# About this memory directory

These files are the EngineeringTeam plugin dogfooding itself: the plugin was
run on this repository and promoted its own findings here, following
`skills/engineering-team/references/memory-promotion.md`. They double as a
worked example of what promoted memory looks like (evidence paths, origin run,
confidence, review triggers).

For your own projects, committing `.engineering-team/memory/` is optional:

- Commit it when the team wants shared, reviewable repo knowledge that
  survives sessions and machines.
- Git-ignore it when memory is personal or experimental.

Either way, treat memory as advisory. Current source code, tests, and
generated outputs always win over memory, and entries here may be stale —
check the `Review trigger` and `Last verified` lines before relying on one.
